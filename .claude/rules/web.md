# Public web rules

- The browser consumes only sanitized static JSON generated by `scripts/export_public_bundle.py`.
- Never expose secrets, database URLs, raw private notes, admin data, password material, or an Ollama endpoint.
- Keep TypeScript strict and reuse shared types/data helpers rather than duplicating parsing logic in pages.
- Every probability, premium, forecast, and status view must show its timestamp/freshness context.
- Preserve transparent methodology, evidence provenance, revision history, exclusions, and sample-size warnings.
- Design mobile-first enough that all primary content works without horizontal scrolling; wide secondary tables may scroll.
- Maintain keyboard access, semantic structure, readable contrast, and meaningful empty/error/loading states.
- Do not use demo data in a production build without a prominent explicit label.
- After frontend or public-data-contract changes, run `npm run check` and `npm run build` from `web/`.
